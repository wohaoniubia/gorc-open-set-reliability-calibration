# Omitted Resources

The repository contains compact source tables, final figure files, and scripts. The following resources are intentionally not included:

- COCO 2017 images and annotations. Obtain COCO from the official dataset distribution before rerunning detector-level experiments.
- LVIS images and annotations. Obtain LVIS from the official dataset distribution and follow the protocol definitions in the analysis scripts.
- YOLO-World and Grounding DINO model weights. Download model checkpoints from their original project releases under the corresponding licences.
- Large detector-output and scored-candidate caches. These files are substantially larger than the tabular sources included here and should be regenerated locally or stored in a separate data repository.

The included CSV files are sufficient to check the reported tables, figure source values, and additional diagnostic summaries.
