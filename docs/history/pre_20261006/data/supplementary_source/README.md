# Additional Source Tables

This folder contains compact source tables for additional diagnostics and machine-readable summaries that support the figures and tables.

- `s_policy_grid.csv` records the calibration policy grid used for operating-mode selection.
- `s_exact_ap_bootstrap.csv` records fixed-policy exact AP bootstrap summaries.
- `s_repeated_split_exact_ap.csv` records repeated calibration/test split diagnostics.
- `s_calibration_budget.csv` records calibration-budget sensitivity summaries.
- `s_known_label_only_diagnostic.csv` records the known-label-only threshold diagnostic.
- `s_preference_table.csv` records preference-sensitive accepted-output risk values.
- `s_prompt_stress.csv` records the Grounding DINO prompt-template stress summary.
- `s_detector_config.csv` records detector configuration fields and reproducibility boundaries.
